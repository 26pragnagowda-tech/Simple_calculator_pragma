Simple Calculator Using Python

Description

This project is a simple calculator developed using Python. It accepts two numbers from the user and performs basic arithmetic operations.

Objective

To understand arithmetic operators, user input, conditional statements, and basic program logic in Python.

Tools Used

- Python
- VS Code / PyCharm

Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulus (%)
- Handles division by zero and modulus by zero.
- Displays results clearly.

Inputs

1. First number
2. Second number
3. Operation choice (1–5)

Output

The program displays the result of the selected arithmetic operation. If the user enters zero as the second number for division or modulus, an error message is displayed.

How to Run

1. Save the Python program as "calculator.py".

2. Open the terminal in VS Code.

3. Run the command:
   
   "python calculator.py"

4. Enter the two numbers and select an operation.

5. View the result.

Conclusion

This project demonstrates the use of Python arithmetic operators, input handling, and conditional statements to create a simple calculator.
